## 🔧 Open-Source Voice AI Toolkit

> TypeScript libraries distilled from real production voice-agent problems. MIT licensed · tested.

| Library | What it does |
|---|---|
| 🗣️ **[stt-normalize](https://github.com/naveenkumarans/stt-normalize)** | Turns messy speech-to-text into clean data — spoken digits ("oh", "double five"), phone numbers, ZIP codes, spoken dates, filler stripping |
| 🛡️ **[voice-guardrails](https://github.com/naveenkumarans/voice-guardrails)** | Runtime guardrails for LLM voice agents — persona-leak detection, duplicate-response suppression, TTS-safe sanitization |
| 🎯 **[asr-boost-gen](https://github.com/naveenkumarans/asr-boost-gen)** | Weighted ASR boost-phrase configs — golden-set merging, override precedence, dedupe, engine phrase caps |
| ☎️ **[dtmf-capture](https://github.com/naveenkumarans/dtmf-capture)** | Deterministic DTMF digit-capture state machine for IVR — timeouts, terminator keys, validators. Born from fixing a 44% capture-failure rate |
